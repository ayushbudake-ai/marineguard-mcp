# 📄 Reporting & GIS Exporters Layer

This package generates multi-format mission reports and maritime GIS data layers.

## Modules

- **`pdf_exporter.py`**: Automated PDF mission report generation using ReportLab.
- **`geojson_exporter.py`**: Maritime GeoJSON layer generation for GIS mapping (QGIS/ArcGIS).
- **`json_csv_report.py`**: Tabular CSV and structured JSON contact log exporters.
- **`s100_exporter.py`**: S-100 / S-124 maritime navigation hazard warning notices.
- **`coordinate_validator.py`**: Strict geographic coordinate validation and range checks.
