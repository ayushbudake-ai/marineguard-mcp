# MarineGuard Side-Scan Sonar (SSS) Dataset - marineguard_sss

## 1. Dataset Purpose
This dataset is constructed specifically for the Side-Scan Sonar (SSS) marine debris detection pipeline in MarineGuard. It provides standardized YOLO object detection annotations for abandoned, lost, or discarded fishing gear (ghost nets) in side-scan sonar waterfall/tile imagery.

## 2. Source & Provenance
- Source Dataset: DRISHTI - Side-Scan Sonar Training Splits (Fazal et al., SIH 2026, PS 26057; https://github.com/Rehan9599/Sonar-Drishti).
- Source Directory: C:\MarineGuard-SSS\DRISHTI
- Licence: Creative Commons Attribution-ShareAlike 4.0 International (CC-BY-SA-4.0).
- Upstream Attributions:
  - Background (bg): SubPipe / SubPipeMini2 (Alvarez-Tunon et al., OceanScan-MST, CC-BY-4.0; https://zenodo.org/records/10808161). Real object-free seabed survey strips used as hard negative samples.
  - Ghost Net (synth_ghost_net): Procedural acoustic generator (build_synthetic_data.py), composited over real background seabed canvases with simulated acoustic highlight and acoustic shadow physics (CC-BY-SA-4.0).

## 3. Taxonomy Mapping & Class Conversion
- DRISHTI ghost_net (Class 3) -> MarineGuard net (Taxonomy ID 29) -> Local YOLO Class 0 (100% Synthetic)
- DRISHTI bg -> MarineGuard Hard Negative (Empty label file, Real seabed from SubPipeMini2)

### Excluded Classes
The following classes from DRISHTI were deliberately excluded:
- submarine_pipeline (pipe*, Class 1): Infrastructure, not marine debris.
- shipwreck (wreckA*, wreckR*, Class 2): Navigational / archaeological feature, not debris target.
- mine_cylinder (mine*, synth_mine_cylinder*, Class 4): Military ordnance, outside marine debris scope.
- crab_pot (Class 0): Omitted upstream in DRISHTI release.

## 4. Dataset Splits & File Counts
- Train: 900 Ghost Net Images (Positives, 900 objects) + 500 Background Images (Negatives) = 1,400 Images, 1,400 Labels
- Val: 120 Ghost Net Images (Positives, 120 objects) + 70 Background Images (Negatives) = 190 Images, 190 Labels
- Test: 120 Ghost Net Images (Positives, 120 objects) + 70 Background Images (Negatives) = 190 Images, 190 Labels
- Total: 1,140 Ghost Net Images (1,140 objects) + 640 Background Images = 1,780 Images, 1,780 Labels

- Split partitions (train, val, test) strictly preserve DRISHTI upstream split assignments without reshuffling.
- Every positive image (synth_ghost_net_*.png) has an exact 1:1 matching label file with normalized bounding boxes converted to class 0.
- Every negative image (bg_*.jpg) has an exact 1:1 matching empty label file (.txt), providing hard negative seabed examples to suppress false positives.

## 5. Preprocessing Notice
- Already Applied Upstream: All tiles in DRISHTI have already been preprocessed with Lee speckle filter + CLAHE (clip limit 3.0, 8x8 grid, 7x7 Lee kernel).
- CRITICAL INSTRUCTION: DO NOT apply Lee speckle filtering or CLAHE a second time to these source images.

## 6. Critical Limitations & Synthetic Data Warning
- Synthetic Ghost Net Imagery: The ghost net contacts (synth_ghost_net) are generated by procedural simulation of acoustic scattering and acoustic shadow modeling on seabed canvases.
- Metric Interpretation: Model precision, recall, and mAP measured on this dataset represent synthetic-on-synthetic performance. They MUST NOT be interpreted or reported as verified real-world ocean deployment metrics. Real-world validation remains dependent on in-situ acoustic data collection.
