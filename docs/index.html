Codebase

6 Core Modules

Each module is independently testable and follows Pydantic V2 typed contracts throughout.

Module 1
🔧
Sensor Suite Compiler
marineguard/compiler/
Parses AUV/ROV spec YAML files and emits executable MCP tool stubs automatically — zero per-platform manual coding.
sensor_parser.py
geometry_solver.py
pipeline_generator.py
mcp_emitter.py
Module 2
🔍
Detection & Fusion Engine
marineguard/detection/
Multi-modal target detection with Dempster-Shafer confidence-weighted fusion across all active sensors.
side_scan.py — shadow & highlight analysis
sas.py — sub-cm coherent imaging
optical.py — YOLOv8-style detection
bathymetry.py — depth anomaly detection
fusion.py — evidence combination
Module 3
🔥
Mission Firewall
marineguard/firewall/
Formal risk taxonomy (LOW → CRITICAL) enforced before every vehicle action. Gates on battery %, comms link, and detection confidence.
risk_taxonomy.py
policy.py
operator_ui.py
Module 4
📋
Explainable Trace Engine
marineguard/trace/
Step-by-step JSON reasoning logs and multi-modal visual evidence overlays — sonar waterfall, optical crop, SAM2 mask, bathymetry cross-section.
tracer.py — decision log per target
evidence_overlay.py — composite image
visualizer.py — matplotlib pages
Module 5
🤖
MCP Tool Server
marineguard/mcp_server.py
Central MCP server exposing 9 compiled tools to any MCP-compatible LLM agent. Fully type-safe via Pydantic V2 schemas.
mcp_server.py
schemas.py — shared contracts
Module 6
📤
Standards Exporters
marineguard/exporters/
Standards-compliant output packages for official MoES submission — legally auditable PDF, geospatial GeoJSON, and IHO S-100 hydrographic XML.
pdf_report.py — ReportLab mission PDF
geojson_export.py — feature collection
s100_export.py — IHO S-100 XML
API

MCP Tools Interface

9 dynamically compiled tools exposed to any MCP-compatible LLM agent or orchestrator.

Tool Name Description
marine_debris_survey()Full autonomous mission orchestration — start to finish survey pipeline
start_side_scan_survey()Activate SSS acquisition at specified frequency & swath width
detect_debris_sonar()Run sonar shadow/highlight analysis detection pipeline
start_sas_survey()SAS coherent imaging pass (Kongsberg HUGIN 3000 — compiled dynamically)
detect_debris_optical()YOLOv8-style optical bounding box detection pass
start_bathymetry_mapping()MBES depth mapping & seafloor protrusion detection
classify_target()Fuse all sensor results with Dempster-Shafer → final classification
trigger_close_inspection()Approach & re-image target at specified altitude
export_report()Generate PDF / GeoJSON / IHO S-100 evidence package

Get Started

Quick Start

Up and running in under 2 minutes.

Step 1
Clone & Install
git clone https://github.com/ayushbudake-ai/marineguard-mcp.git
cd marineguard-mcp
pip install -r requirements.txt
Step 2
Run Tests
pytest tests/ -v
# 4 test files · compiler, detection,
# firewall, trace
Step 3
Streamlit Web App
streamlit run streamlit_demo.py
# Opens MoES Web Command Center
# at localhost:8501
Step 4
CLI Demo
python demo.py --simulate
# Rich interactive terminal
# full mission simulation
